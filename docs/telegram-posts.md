# Посты канала → блог сайта

Сайт сам забирает новые посты из канала [informatika_kege_itpy](https://t.me/s/informatika_kege_itpy)
примерно раз в 30 минут. В блог попадают только посты с хештегом рубрики, остальное (опросы,
объявления, реклама, кружки) на сайт не идёт.

| Хештег в посте | Рубрика на сайте | Как выглядит |
|---|---|---|
| `#ЕГЭ1`–`#ЕГЭ27` + слово «Разбор» | Разборы заданий | Карточка с номером задания, фильтр по номеру, метки «Уровень», «Сборник», «Источник» |
| `#tpy` | Теория Python | Сиреневая карточка с темой по заголовку (`for / while`, `str`, `turtle`…), статья с кодом |
| `#useful` | Полезное о ЕГЭ | Голубая карточка с планшетом, статья со ссылками на файлы |
| `#news` или `#новости` | Новости | Персиковая карточка «Что нового?»; вкладка появится с первым таким постом |
| `#view` | Видео | Карточка с кадром из видео, ведёт сразу на видео |

Сборник задачи берётся из хештега рядом с номером: `#kege`/`#КЕГЭ` → КЕГЭ, `#yandex` → Яндекс,
`#statgrad` → СтатГрад, `#polyakov` → К. Поляков, `#reshu` → Решу ЕГЭ. `#реклама` убирает пост с сайта.

## Разбор задачи

```
🚩 Разбор номера 25355 #kege по информатике #ЕГЭ16
Автор: ЕГКР 13.12.25
Уровень: Средний

🚩 Условие задачи:
<текст условия — лучше цитатой>

🚩 Теоретическая справка:
<цитата>

👩‍💻 Код решения:
<код блоком>
Ответ: 47

👩‍💻 Комментарии к коду:
1⃣ <строка кода моноширинным>
<что она делает>
2⃣ …
```

- Заголовок на сайте собирается сам: «Задание 16 ЕГЭ: разбор задачи 25355». Несколько тегов
  (`#ЕГЭ19 #ЕГЭ20 #ЕГЭ21`) дают «Задания 19–21 ЕГЭ».
- «Автор:» и «Уровень:» становятся метками; строки с двоеточием в конце — подзаголовками.
- Пункты с эмодзи-цифрами превращаются в нумерованный список.
- Ссылки на канал, чат, бота и `@ilandroxxy` в конце поста на сайт не переносятся.
- Пост-анонс со ссылкой на статью в другом месте на сайт не попадёт: нужен текст условия или код.

## Python, Полезное, Новости, Видео

Заголовок статьи — строка с хештегом (`… #tpy`), без эмодзи. Остальное переносится как есть:
жирный, курсив, код, цитаты, ссылки, фото. У видео сайт берёт кадр и ссылку на ролик, само видео
не скачивает.

## Правки и повторы

- Исправленный пост обновится на сайте, если он среди 20 последних. Старые правки подтянет
  `npm run blog:sync -- --all`.
- Удалённый из канала пост со страницы сам не пропадёт: уберите у него хештег рубрики (исчезнет со
  следующей синхронизацией) или удалите файл `content/blog/posts/<id>.json`.
- Повторно опубликованный разбор той же задачи (или тот же текст `#tpy`) показывается один раз —
  самая свежая версия; адрес страницы при этом не меняется.
