# Посты канала → блог сайта

Сайт сам забирает новые посты из канала [informatika_kege_itpy](https://t.me/s/informatika_kege_itpy)
раз в день, в 04:00: посты за день появляются на сайте к утру. В блог попадают только посты по формату ниже:
**первая строка поста — заголовок с хештегом рубрики**. Всё остальное (опросы, объявления, реклама, кружки,
посты, которые начинаются со вступления) на сайт не идёт.

| Хештег в посте | Рубрика на сайте | Как выглядит |
|---|---|---|
| `#ЕГЭ1`–`#ЕГЭ27` + слово «Разбор» | Разборы заданий | Карточка с номером задания, фильтр по номеру, метки «Уровень», «Сборник», «Источник» |
| `#tpy` | Теория Python | Сиреневая карточка с темой по заголовку (`for / while`, `str`, `turtle`…), статья с кодом |
| `#useful` | Полезное о ЕГЭ | Голубая карточка с планшетом, статья со ссылками на файлы |
| `#news` или `#новости` | Новости | Персиковая карточка «Что нового?»; вкладка появится с первым таким постом |
| `#view` | Видео | Карточка с кадром из видео, ведёт сразу на видео |

Сборник задачи берётся из хештега рядом с номером: `#kege`/`#КЕГЭ` → КЕГЭ, `#yandex` → Яндекс,
`#statgrad` → СтатГрад, `#polyakov` → К. Поляков, `#reshu` → Решу ЕГЭ. `#реклама` убирает пост с сайта.

## Разбор задачи

```
🚩 Разбор номера 25355 #kege по информатике #ЕГЭ16
Автор: ЕГКР 13.12.25
Уровень: Средний

🚩 Условие задачи:
<текст условия — лучше цитатой>

🚩 Теоретическая справка:
<цитата>

👩‍💻 Код решения:
<код блоком>
Ответ: 47

👩‍💻 Комментарии к коду:
1⃣ <строка кода моноширинным>
<что она делает>
2⃣ …
```

- Заголовок на сайте собирается сам: «Задание 16 ЕГЭ: разбор задачи 25355». Несколько тегов
  (`#ЕГЭ19 #ЕГЭ20 #ЕГЭ21`) дают «Задания 19–21 ЕГЭ».
- «Автор:» и «Уровень:» становятся метками; строки с двоеточием в конце — подзаголовками.
- Пункты с эмодзи-цифрами превращаются в нумерованный список. Пустые строки между пунктами не нужны:
  каждая строка, которая начинается с эмодзи-цифры, — новый пункт.
- Ссылки на канал, чат, бота, `@ilandroxxy` и упоминания Дзена на сайт не переносятся.
- Пост-анонс со ссылкой на статью в другом месте на сайт не попадёт: нужен текст условия или код.

## Python, Полезное, Новости, Видео

Заголовок статьи — строка с хештегом (`… #tpy`), без эмодзи. Остальное переносится как есть:
жирный, курсив, код, цитаты, ссылки, фото. У видео сайт берёт кадр и ссылку на ролик, само видео
не скачивает.

## Чтобы пост точно попал на сайт

- Хештег рубрики — только в первой строке, рядом с заголовком. Пост, который начинается со вступления
  («Делюсь с вами шпаргалкой…»), а хештег стоит ниже, на сайт не попадёт. Строка из одних эмодзи перед
  заголовком не мешает.
- Разбору нужен тег номера (`#ЕГЭ16`), слово «Разбор» или «Условие» и условие цитатой или код. Без этого пост
  считается анонсом. Посту другой рубрики нужно хотя бы 15 слов или код.
- В заголовке не пишите «Телеграм»/«Telegram»: такие посты считаются постами о самом мессенджере и на сайт
  не идут.
- Строка со ссылкой на t.me, со словом «телеграм» или с Дзеном выпадает целиком. Не ставьте полезный текст
  в одну строку с ними.

## Правки, удаление и повторы

Раз в день сайт перечитывает канал целиком.

- Исправленный пост обновится на сайте со следующей синхронизацией, каким бы старым он ни был.
- Удалённый из канала пост пропадёт с сайта со следующей синхронизацией вместе со своими картинками. Пост,
  у которого убрали хештег рубрики или сломали формат, тоже уйдёт с сайта.
- Если за раз «пропало» много статей (больше 10 и больше 10%), сайт ничего не удаляет и пишет об этом в лог:
  скорее Telegram отдал неполную ленту. Если посты действительно удалили пачкой, на сервере
  `npm run blog:sync -- --all --force` (команда целиком — в `deploy/server/README.md`).
- Повторно опубликованный разбор той же задачи (или тот же текст `#tpy`) показывается один раз —
  самая свежая версия; адрес страницы при этом не меняется.
