# Шаблон статьи на Дзене

Статьи с Дзена автоматически переносятся в блог на сайте. Чтобы на сайте у разбора появились номер задания,
метки и кнопка записи по теме, держите такую структуру. Отступать можно — статья всё равно перенесётся,
просто без этих деталей.

## Разбор задачи

**Заголовок** — номер задачи и хештег с номером задания ЕГЭ:

```
Разбор номера 23189 #КЕГЭ по информатике #ЕГЭ5
```

`#ЕГЭ5` обязателен: по нему сайт понимает, что это задание 5. На сайте заголовок станет
«Задание 5 ЕГЭ: разбор задачи 23189».

**Первая строка** — источник и уровень (перенос строки — Shift + Enter):

```
Автор: Основная волна 10.06.25        ← можно сделать ссылкой на вариант
Уровень: Базовый
```

Можно писать «Автор задачи: …» и ставить «Уровень» отдельным абзацем — на сайте это всё равно станет
метками под заголовком («Источник: …», «Уровень: …»).

**Разделы** — блоком «Заголовок» в редакторе Дзена:

1. `Условие задачи:` — текст условия. Первый абзац условия станет описанием статьи в списке.
2. `Теоретическая справка:` — по желанию, можно цитатой.
3. `Код решения:` — скриншот кода, в подписи ответ («Ответ: 31»).
4. `Комментарии к коду:` — нумерованный список. В каждом пункте строка кода **жирным**,
   пояснение — на следующей строке (Shift + Enter). На сайте строка станет кодом.

**Кнопка записи (по желанию)** — отдельный абзац, начинающийся с «Пробное:»:

```
Пробное: задачи с делителями не поддаются? Разберём их вместе на бесплатном пробном занятии.
```

Этот текст станет надписью над кнопкой записи на сайте, а из самой статьи на сайте пропадёт. Одно
предложение, без ссылок. Если строки нет, сайт напишет сам: «Задание 5 вызывает трудности? Разберём его
вместе на бесплатном пробном занятии».

**Концовка** — цитаты со ссылками на Telegram-каналы оставляйте как есть: на сайте они убираются
автоматически (вместо них там своя кнопка записи).

## Обычная статья (не разбор)

Заголовок без `#ЕГЭ…`, дальше — абзацы, заголовки, списки, цитаты, картинки. Первая картинка станет обложкой
в списке статей. Строку «Пробное: …» тоже можно добавить.

## Как опубликовать на сайте

После публикации на Дзене разработчик запускает импорт — подтянутся только новые статьи:

```bash
npm run blog:import -- https://dzen.ru/informatika_kege_itpy
```
